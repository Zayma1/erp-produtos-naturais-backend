🌿 ERP Natural — MVP

Sistema ERP (Enterprise Resource Planning) desenvolvido para empresas que trabalham exclusivamente com produtos naturais, oferecendo uma solução centralizada para gerenciamento de estoque, produtos, fornecedores, clientes, vendas e operações entre unidades.

O projeto tem como principal objetivo fornecer uma base simples, escalável e modular para controlar as principais operações de um negócio de produtos naturais.

📌 Sobre o Projeto

O ERP Natural é um sistema de gestão empresarial desenvolvido inicialmente como um MVP (Minimum Viable Product).

A aplicação busca centralizar informações e processos que normalmente são realizados de forma descentralizada, permitindo maior controle sobre:

Estoque
Produtos
Categorias
Entradas e saídas
Compras
Vendas
Clientes
Fornecedores
Usuários e vendedores
Comissões e metas
Promoções e ofertas
Transferências entre unidades
Indicadores e gráficos
Operações multiunidade

A arquitetura foi pensada para permitir a evolução futura do sistema sem comprometer a organização inicial do projeto.

🎯 Objetivos do MVP

O MVP tem como principais objetivos:

Centralizar o gerenciamento do estoque.
Facilitar o cadastro e gerenciamento de produtos naturais.
Controlar entradas e saídas de produtos.
Registrar vendas e manter seu histórico.
Gerenciar fornecedores e pedidos de compra.
Permitir o gerenciamento de múltiplas unidades.
Controlar usuários, vendedores, permissões e acessos.
Disponibilizar indicadores para acompanhamento do negócio.
Permitir exportação de dados.
Criar uma base sólida para futuras funcionalidades do ERP.

🚀 Executando o Projeto
Backend

Clone o projeto:

git clone <repository-url>
cd erp-natural/backend


Execute:

./mvnw spring-boot:run


No Windows:

mvnw.cmd spring-boot:run

Frontend

Entre no diretório:

cd frontend


Instale as dependências:

npm install


Execute o projeto:

npm run dev

🐘 Banco de Dados

Exemplo de configuração:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=erp_natural
DB_USERNAME=postgres
DB_PASSWORD=postgres


As configurações reais devem ser mantidas em variáveis de ambiente e não devem ser versionadas no Git.
